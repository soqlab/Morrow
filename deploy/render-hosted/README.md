# Hosted Morrow on Render

**Written for: the operator bringing up app.morrow.soqlab.com.**

`render.yaml` defines `morrow-app` (one Starter web service, 512 MB, with a 1 GB disk) and
`morrow-db` (Render Postgres, basic-256mb). Together about $13 a month. The free demo,
`morrow-demo`, is a separate service and is not affected.

One container runs the API, the Celery worker with beat embedded (solo pool) and Redis on
localhost; see `Dockerfile` and `start.sh`. Measured locally, the API takes about 170 MB once
pages are loaded. If Render's memory graph sits near 512 MB, move the service to Standard.

## Values the Blueprint asks for

| Variable | What to enter |
|---|---|
| `MORROW_VAULT_MASTER_KEY` | A Fernet key: `python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"`. Keep a copy: without it a restored backup cannot be decrypted. |
| `MORROW_ADMIN_EMAIL` | The first customer-side account (owner of the first organization). |
| `MORROW_ADMIN_PASSWORD` | Its password: at least 12 characters, mixed. Only read when the account table is empty. |

Everything else is either in `render.yaml` or generated by Render.

## Operator portal

`/vendor-admin` signs in with a named operator key (`MORROW_PLATFORM_OPERATORS` holds only its
SHA-256) and an authenticator app. The first sign-in asks you to enrol the authenticator; do that
straight away, because the enrolment window closes once the first owner has one. A new key:
`python -m services.platform_operators --name <name> --role owner`.

## Why staging, not production

The production startup check requires customer sign-in through an external identity provider
(RS256 with a JWKS URL). The built-in password sign-in only issues HS256 tokens, so this runs as
`MORROW_ENVIRONMENT=staging`, which keeps MFA and the refusal of the shared platform key. Before
opening sign-ups to the public, work through `docs/LAUNCH_CHECKLIST.md`.

## Domain

Render dashboard → morrow-app → Settings → Custom Domains → `app.morrow.soqlab.com`, then a
Cloudflare CNAME `app.morrow` → the service's onrender.com address, DNS only. If that address
is not `morrow-app.onrender.com`, add it to `MORROW_ALLOWED_HOSTS`.
