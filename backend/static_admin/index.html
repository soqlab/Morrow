    Create API key

    read = viewer (GET only), write = operator, admin = admin. Keys can never call platform, admin, or credential routes.

    Key hygiene

    How keys behave once issued.
    • Rotate with a grace period so deployments can switch before the old key stops working.
    • Revocation is immediate on this server and reaches other replicas within PQC_API_KEY_CACHE_SECONDS.
    • A read key is refused on any request that is not GET, HEAD, or OPTIONS.
    • The key's organization is authoritative; an x-org-id header cannot point it at another tenant.

    Maintenance mode

    While on, customer writes answer 503 with your message. Sign-in, reads, platform administration, health and status keep working.
    unknown

    What maintenance changes

    Scope of the switch.
    • Customer requests other than GET, HEAD and OPTIONS answer 503 with your message.
    • Sign-in, reads, health, status and every platform administration route keep working.
    • The expected end is informational: writes stay paused until an operator turns maintenance off.
    • Pair it with an announcement so customers see the notice before they try to write.
