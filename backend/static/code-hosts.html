What Morrow can do with the token

Only what the permissions you choose allow, on the repositories you choose. Morrow uses it to create a branch, commit the proposed change to that branch and open a pull request against your default branch. The token is encrypted as soon as it arrives and is never shown again; remove the connection here, or revoke the token at your code host, to stop it.
