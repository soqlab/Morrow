What Morrow does with the credentials

Only reads: it lists and describes certificates and key metadata. Give it a read-only account where the vendor offers one. The credentials are encrypted as soon as they arrive and are never shown again. Scheduled sync is off until you choose an interval for a connection; remove the connection here, or revoke the credential at the vendor, to stop it.

These connectors were built and tested against each vendor's published API documentation and example responses, not against live accounts. If a sync reports something unexpected, the message says which vendor answered and how.
