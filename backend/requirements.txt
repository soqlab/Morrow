# Transitive dependencies pinned for security only.
#
# The policy above is not to pin transitives, but pip-audit (see .github/workflows/security.yml)
# reported known vulnerabilities in these, and each is reachable at runtime: urllib3 carries every
# outbound HTTP request, protobuf backs the google-cloud clients and OTLP export, pyasn1 is used
# through the SAML and RSA paths, pillow renders images in the PDF compliance export, and
# python-dotenv arrives with uvicorn[standard]. Pinning them keeps a resolver from quietly
# selecting a vulnerable version again.
