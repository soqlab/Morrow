# Format: <protocol> <host>[:port] [hint]
#   protocol  tls | ssh
#   hint      free text: where the host was expected to sit when it was picked. It is NOT a label.
#             Labels come only from accuracy/reference_probe.py (OpenSSL / OpenSSH, never Morrow).
#
# Every host here serves the general public on that port (a public website, or the public SSH
# endpoint of a code-hosting or shell service). Nothing internal, nothing that needs an account to
# be reached. Hosts that ask not to be probed go in optout.txt and are skipped by every script.
